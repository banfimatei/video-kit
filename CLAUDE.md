# video-kit — Claude playbook

Remotion 4.0.529 toolkit (repo root, `@banfimatei/video-kit`) plus a render
service (`service/`, npm workspace, deployed on Railway). Usage and API: [README.md](README.md).

## Layout

- `src/` — the library. Entries: `.` (runs inside compositions: `Sfx`,
  `SfxCues`, `VoiceTrack`, `resolveSound`, plus core), `./core` (schemas and
  `fitScenesToVoice`, no assets, safe in Node), `./node` (TTS,
  `renderComposition`, site packing, CLI), `./client` (service client, fetch
  only). The root entry imports `.wav` files that only a bundler understands,
  so Node code must import `./core` or `./node`, never `.`.
- `assets/sfx/` — house cues, generated by `scripts/make-sfx.ts` (deterministic).
- `service/src/` — Hono API, job store (JSON files, atomic writes), queue, runner, sites.
- `service/remotion/` — built-in templates, bundled to `service/bundle` at build time.

## Rules

- Load the `remotion-best-practices` skill before writing Remotion code; add
  `@remotion/*` packages at the exact same version as `remotion`.
- The service and library share one copy of Remotion and React through the
  workspace. Don't add them to the service's own nested node_modules.
- Nothing in the request path may throw from a stream callback or leave a
  promise unhandled: either takes the whole process down. See the tar filter
  in `sites.ts` and `JobStore.persist`.
- Voice clips reach the headless Chrome over `http://127.0.0.1:$PORT/internal/voice/…`,
  which answers loopback only. Render files are served only by signed link or bearer key.
- A render captures its site's version directory when submitted; redeploying a
  site must never change files under a running render.
- Templates validate props in Node (`BUILTIN_TEMPLATES[id].prepare`) so bad
  input is a 400, not a failed job.

## Verify

```bash
npm run typecheck && npm test
cd service && npm run build && npm run bundle
RENDER_API_KEY=dev-key-0123456789ab DATA_DIR=/tmp/vk node dist/src/index.js &
VIDEO_KIT_URL=http://localhost:8080 VIDEO_KIT_API_KEY=dev-key-0123456789ab SMOKE_TTS=espeak npm run smoke
```

In a Claude Code cloud session: set
`REMOTION_BROWSER_EXECUTABLE=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`
(remotion.media is blocked) and `apt-get install espeak-ng` for the offline voice.
